Tips
  • ⌥. toggles Tenote from anywhere
  • Just type — notes save automatically as Markdown files
  • Paste an image to drop it inline (it’s copied into your notes folder)
  • Select text, then ⌘B bold or ⌘I italic
  • #tags become chips under the note
  • Drag the window edges to resize
